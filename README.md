### 🎯 Sobre Mim

Desenvolvedor Web Full Stack com foco na construção de aplicações escaláveis, performáticas e seguras. Atuo no ciclo completo de desenvolvimento de software (*End-to-End*), desde a concepção de produto e prototipação em UX/UI (Figma) até a arquitetura de APIs, bancos de dados e testes automatizados.

Possuo histórico de treinamento de alta performance no ecossistema da WorldSkills (Modalidade #17 - Tecnologias Web) pelo SENAI São Paulo, onde aperfeiçoei a entrega de software sob padrões internacionais de qualidade de código, resolução de problemas sob pressão e arquitetura limpa.

- ⚙️ **Core Stack:** PHP (Laravel), JavaScript/TypeScript (Next.js, React), Node.js, MySQL.
- 🧪 **Qualidade & Processos:** TDD com Pest PHP, Git Flow, CI/CD e gerenciamento de permissões (RBAC / Multi-tenant).
- 🎨 **Design & Produto:** Prototipação de Alta Fidelidade no Figma, UX Research, Design Systems e Acessibilidade (WCAG).
- 🔄 **Automação & Cloud:** n8n, Servidores Linux, Hostinger, hospedagem e rotinas de deploy.
